# 05 — How to Add a New Dataset & Run Analysis

## Supported Input Formats

| Format | How to identify | Source |
|---|---|---|
| **Scenario CSV** | Header contains `post_id`, `account_id`, `username` | Generated by `scenario/generate_scenario.py` |
| **X/Twitter IO Archive** | Header contains `tweetid`, `tweet_text` | Twitter/X Information Operations Archive |
| **IRA Troll Archive** | Header contains `tweet_id`, `author`, `publish_date` | FiveThirtyEight IRA dataset |
| **JSON** | `.json` extension, array of Post objects | Pre-normalized output from a previous run |

The system auto-detects format — no manual flag required.

---

## Option A: Upload via the Web UI

1. Start the server: `python src/main.py`
2. Open `http://127.0.0.1:8000` in your browser
3. Click **Ingestion** tab (top-right)
4. Drag & drop or select your CSV file → click **Upload**
   - You get back a `dataset_id` like `u_a3b5c7`
5. Click **Run Analysis** next to your uploaded dataset
6. Switch to **Overview** tab to see the results

---

## Option B: Run Analysis via API (curl / Python)

```bash
# Step 1: Upload the file
curl -X POST http://127.0.0.1:8000/api/datasets \
  -F "file=@/path/to/your_posts.csv"
# Response: {"dataset_id": "u_a3b5c7", "posts": 1234, "accounts": 321}

# Step 2: Run analysis
curl -X POST http://127.0.0.1:8000/api/datasets/u_a3b5c7/analyze
# Response: {"dataset_id": "u_a3b5c7", "posts": 1234, "accounts": 321, "runtime_ms": 4200, "campaigns": [...]}

# Step 3: View campaigns
curl http://127.0.0.1:8000/api/datasets/u_a3b5c7/graph
curl http://127.0.0.1:8000/api/datasets/u_a3b5c7/timeline

# Step 4: Classify a campaign with IBM Bob
curl -X POST http://127.0.0.1:8000/api/datasets/u_a3b5c7/campaigns/c1/classify

# Step 5: Generate the escalation brief
curl http://127.0.0.1:8000/api/datasets/u_a3b5c7/brief > brief.html
```

## Option C: Run Directly via Python Script

```python
from src.engine.normalize import load_posts
from src.engine.pipeline import analyze

posts = load_posts("path/to/your_posts.csv")
result = analyze(dataset_id="my_dataset", posts=posts)

print(f"Found {len(result['campaigns'])} campaigns")
for c in result['campaigns']:
    print(f"  {c['id']}: score={c['score']}, size={c['size']}, hashtag={c['top_hashtag']}")
```

Output artifacts are written to `data/runs/my_dataset/`.

## Required CSV Schema (Scenario Format)

If you're preparing your own CSV (not from a known archive), use these column names:

| Column | Type | Required | Description |
|---|---|---|---|
| `post_id` | string | ✅ | Unique post identifier |
| `account_id` | string | ✅ | Unique account/author identifier |
| `username` | string | ✅ | Display name / handle |
| `created_at` | integer | ✅ | Unix timestamp in seconds |
| `text` | string | ✅ | Full post text |
| `repost_of` | string | ❌ | Original post ID if this is a repost |
| `reply_to` | string | ❌ | Target post/account ID if this is a reply |
| `urls` | string | ❌ | Space-separated list of URLs |
| `hashtags` | string | ❌ | Space-separated list of hashtags (with or without `#`) |
| `account_created_at` | integer | ❌ | Unix timestamp of account registration (enables `fresh_accounts` scoring) |

Example row:
```csv
post_id,account_id,username,created_at,text,repost_of,reply_to,urls,hashtags,account_created_at
p001,a001,@user1,1700000000,"Dam water level rising! Everyone flee now",,, ,#SundarpurAlert,1699000000
```

## Tuning the Analysis

All thresholds are set in `src/.env` (copy from `src/.env.example`):

| Variable | Default | Effect |
|---|---|---|
| `TIME_WINDOW_SECONDS` | `60` | Raise to catch slower coordination (e.g. `300`) |
| `MIN_EDGE_WEIGHT` | `2` | Raise to filter noise in large datasets (e.g. `3` or `5`) |
| `BOB_MAX_COST` | `0.25` | Raise for longer Bob analysis (e.g. `0.5` for complex campaigns) |

## What Gets Saved

After a successful analysis of dataset `my_dataset`:

```
data/runs/my_dataset/
├── posts.json          All normalized posts (used for all subsequent queries)
├── campaigns.json      All detected campaigns with CIB scores
├── graph.json          Cytoscape-format nodes and edges
├── timeline.json       Per-minute activity buckets
├── toolkit.db          SQLite (intermediate, can be deleted)
└── bob/
    ├── c1.json         Bob verdict for campaign c1 (cached after first classify)
    ├── c2.json         Bob verdict for campaign c2
    └── summary.json    Executive summary (cached after first brief generation)
```

Re-running analysis overwrites everything except `bob/` (Bob verdicts are preserved as cache).

## Bob Chat OSINT Investigation (Advanced)

After running analysis, you can query the results conversationally using Bob Chat:

```bash
# From the repo root
bob chat
```

Then in Bob Chat:
```
/mode osint-analyst
```

Example queries:
- *"Which accounts started the flood rumour in campaign c2 in dataset my_dataset?"*
- *"List all campaigns in my_dataset sorted by CIB risk."*
- *"Show evidence hashes for campaign c1 under BSA Section 63."*

Bob queries the local FastMCP server (`src/mcp_server/server.py`) which reads directly from `data/runs/`.
